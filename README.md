# برنامه دورکاری هفتگی

تخصیص یک روز دورکاری در هفته برای ۶ نفر، با تقویم جلالی (شنبه تا چهارشنبه).

## امکانات

- تنظیم **۱ یا ۲ روز** دورکاری برای هر نفر (فقط هنگام ساخت اولین برنامهٔ هفته)
- تولید تصادفی فقط برای هفتهٔ خالی و فقط توسط مدیران برنامه (**سهیل** و **فاطمه جودکی**)
- مدیران می‌توانند بعد از انتشار، روز هر همکار را مستقیم تغییر دهند؛ اعلان داخل برنامه برای افراد تغییرکرده ثبت می‌شود
- جابه‌جایی روز با درخواست و تأیید طرف مقابل
- هر نفر پین شخصی دارد؛ با ورود، نامش نمایش داده می‌شود
- ناوبری بین هفته‌ها

## اجرا محلی

```bash
npm install
npm run dev
```

بدون `DATABASE_URL` داده‌ها فقط در حافظهٔ سرور می‌مانند (با ری‌استارت پاک می‌شوند).

برای ذخیره پایدار، یک دیتابیس رایگان [Neon](https://neon.tech) بسازید و در `.env.local` قرار دهید:

```bash
cp .env.example .env.local
# DATABASE_URL و PERSON_PINS را پر کنید
npm run db:push
npm run dev
```

بدون `PERSON_PINS` در حالت لوکال، پین‌های پیش‌فرض `1000` تا `1005` به‌ترتیب برای افراد لیست استفاده می‌شود. هر نفر بعد از ورود می‌تواند پین خودش را عوض کند (در دیتابیس ذخیره می‌شود).

## دیپلوی روی Vercel (رایگان)

1. ریپو را به [Vercel](https://vercel.com) وصل کنید و Framework را Next.js بگذارید.
2. در Neon یک پروژه رایگان بسازید و connection string را کپی کنید.
3. در Vercel → Settings → Environment Variables:
   - `DATABASE_URL` = همان connection string
   - `PERSON_PINS` = یک JSON یک‌خطی (بدون کوتیشن اضافه دور کل مقدار). مثال:

```text
{"سهیل":"1234","پریسا":"2345","فاطمه جودکی":"3456","کاویان":"4567","فاطمه منصوری":"5678","محمد رضا زارع":"6789"}
```

نام‌ها باید دقیقاً با `src/lib/people.ts` یکی باشند. پین‌های پایه در **env** هستند، نه در جدول دیتابیس. جدول `person_pins` فقط وقتی پر می‌شود که کسی پین را از داخل برنامه عوض کند و آن مقدار روی env اولویت دارد.

4. یک‌بار migration را اجرا کنید (لوکال با همان `DATABASE_URL`):

```bash
npm run db:push
```

یا SQL داخل `drizzle/` را در Neon SQL Editor اجرا کنید.

5. بعد از تغییر env حتماً **Redeploy** کنید (بدون آن پین‌های جدید لود نمی‌شوند). لینک عمومی برنامه را نشان می‌دهد؛ تغییر فقط با پین شخصی ممکن است.

## افراد

لیست در `src/lib/people.ts` ثابت است؛ برای تغییر نام همان فایل را ویرایش کنید و کلیدهای `PERSON_PINS` را همگام نگه دارید.
